## How a number reaches the page

1. **Each figure reads only its CSV.** `figures/data.py` assembles one long CSV per figure from the upstream rows it
   plots; a figure module (`fig1_validation_test` … `fig7_memorisation`, `appendix`) holds `plot(df)` and reads no
   file; `render.draw` reads the CSV, draws, checks the width, the type size and the printability of every text,
   and saves.
   - *Why:* the PRD asks for it (S2), and a module without file access cannot read another source by accident.
2. **Every plotted value names its cell.** A figure row carries `source`, `key` and the columns it took;
   `sources.trace` re-reads each cell (`tests/test_figures_trace.py`, AC4). The only arithmetic is an interval:
   ±1.96 stored SE (±1 in the exploratory monthly figure, A6), ±1.96 × |value / t|, or the Wilson interval of a
   stored share and its stored number of trials (Figure 7); bootstrap and placebo bounds are copied.
   - *Why:* "no new analysis" (AC4) becomes a test.
3. **Two simple aggregations of stored files** are NA-14 tables, each recomputed by a test: t33, numpy's quantiles
   (linear, as NA-13) of the Sharpe ratios of NA-13's 100 placebo books per universe, which also reproduces the
   quantiles NA-13's REPORT §7 quotes; t35, each test book's break-even cost, gross mean ÷ turnover, which
   reproduces NA-13's REPORT §6 (8.3, 3.7 and 5.1 bp).
4. **Every caption number is a table cell.** `captions.yaml` cites `{{table/key/column@spec}}` from `keys.json`;
   `[[...]]` marks a label or a design constant. Since the revision pass the captions are written in LaTeX notation
   (`$z_{cc}$`, `$\hat N$`, `$\kappa_h$`) and the uncited-number check reads inside math too.
5. **Every number in a LaTeX table is a table cell.** `figures/latex.py` renders cells of `keys.json` by (table,
   key, column) and lists them per table in `tables/latex.json`; a test checks each cited key exists.
